# Project overview

**Eturlia** is a hybrid Minecraft 1.21.1 server core: Folia's regionized multithreading
plus the NeoForge mod loader in a single fat jar.

- What it is, how it boots, how to build and run it: [`README.md`](./README.md)
- Modder / unsupported-mod policy: [`docs/MODDER_POLICY.md`](./docs/MODDER_POLICY.md)
- Pack audit: [`docs/PACK_COMPAT_ASIC_2026-08.md`](./docs/PACK_COMPAT_ASIC_2026-08.md)
- Region model notes: [`REGION_LOGIC.md`](./REGION_LOGIC.md)

For the upstream Folia design (regions, schedulers, what breaks under region threading)
see [the PaperMC documentation](https://docs.papermc.io/folia/reference/overview).
